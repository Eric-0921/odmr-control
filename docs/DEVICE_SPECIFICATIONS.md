## 1. 系统概述

ODMR Control 系统由三台设备组成，用于光探测磁共振实验：

| 设备 | 型号 | 厂商 | 用途 | 通信接口 |
|------|------|------|------|----------|
| 微波源 | SMB100A | Rohde & Schwarz | 产生 RF 微波信号 | VISA (USBTMC/GPIB/LAN) |
| 锁相放大器 | OE1022D | SSI | 微弱信号检测 | Serial RS-232 (USB转) |
| 激光器 | MSL-U-532nm-300mW | CNI | 激发光源 | Serial RS-232 (USB转) |

## 2. 微波源 SMB100A

### 2.1 性能参数

| 参数 | 数值 | 备注 |
|------|------|------|
| 频率范围 | 100 kHz ~ 12.75 GHz | 扩展可至 40 GHz |
| 最大输出功率 | +27 dBm (实测) | 含衰减器 |
| 功率范围 | -120 ~ +30 dBm | 驱动层硬限制 |
| SSB 相位噪声 | -108 dBc (典型) | @10 GHz, 20 kHz offset |
| 宽带噪声 | -138 dBc | @10 GHz, 30 MHz offset |
| VISA 超时 | 枚举 500ms / 操作 10000ms | 枚举短超时防止 hang |

### 2.2 安全限制

**软件强制限制 (CommandService 层):**

| 条件 | 最大允许功率 | 配置键 |
|------|-------------|--------|
| 有放大器 (`amplifier_installed=true`) | 10 dBm | `smb.max_power_with_amp_dbm` |
| 无放大器 (`amplifier_installed=false`) | 25 dBm | `smb.max_power_without_amp_dbm` |

**功率校验层级:**
1. GUI 前端: 输入框颜色警告 (>80% 橙色 / >95% 红色 / >100% 禁止)
2. 命令层: `CommandService._check_power_limit()` 抛出 `SafetyError`
3. 驱动层: `SMB100ADriver.validate_power()` 硬限制 -120~+30 dBm

**硬件安全:**
- 反向功率保护: 超过数据手册限制可损坏仪器
- 过压类别 II，需保护接地电源
- 保险丝保护最大 20 A
- 仅室内使用，海拔 ≤2000 m
- 禁止打开外壳

**急停机制:**
- `SYS_EMERGENCY_STOP` 命令: 关闭 RF/LF/FM 输出，切回 CW 模式
- 动态扫频超时: 点数 × 驻留 + 30s 裕量

### 3.2 安全限制

**输入保护:**
- 电压输入: ±10V (超出可能损坏 A/D 转换器)
- 交流耦合仅用于信号频率 >10 Hz
- 低于 10 Hz 必须使用直流耦合
- 信号频率接近 50/100 Hz 时禁用陷波器

**工频陷波器:**
- 50/60 Hz 和 100/120 Hz 陷波，衰减 60 dB
- 陷波器中心频率 ±10 Hz 范围内信号也会被衰减
- 会产生一定相位偏移，影响相位测量

**通信参数:**

| 参数 | 数值 | 配置键 |
|------|------|--------|
| 波特率 | 921600 | `lockin.baudrate` |
| 数据位 | 8 | `lockin.bytesize` |
| 校验位 | 无 | `lockin.parity` |
| 停止位 | 1 | `lockin.stopbits` |
| 超时 | 1.0 s | `lockin.timeout` |

**RALL? 批量读取:**
- 每批 20 参数 × 50 点 = 12288 bytes
- 采集间隔 50ms
- 必须验证 `len(raw) == 12288`，不完整数据丢弃
- USB 传输可能丢包，需做完整性校验

**SNAPD? 实时监控:**
- 返回 X/Y/R/θ
- 监控间隔 94ms
- ASCII 查询模式

### 4.3 RS232 通信协议

**串口参数:**

| 参数 | 数值 | 配置键 |
|------|------|--------|
| 波特率 | 9600 | `laser.baudrate` |
| 数据位 | 8 | `laser.bytesize` |
| 校验位 | 无 | `laser.parity` |
| 停止位 | 1 | `laser.stopbits` |
| 数据格式 | 十六进制 | |

**引脚分配 (DB-9):**

| 引脚 | 信号 | 说明 |
|------|------|------|
| 2 | TXD | 发送 (电脑端) / 接收 (激光器端) |
| 3 | RXD | 接收 (电脑端) / 发送 (激光器端) |
| 5 | GND | 信号地 |

**指令集:**

| 功能 | 指令 (十六进制) | 配置键 |
|------|-----------------|--------|
| 设置功率 | `55 AA 05 01 [高字节] [低字节] [校验和]` | `laser.cmd_set_power_template` |
| 关闭激光 | `55 AA 03 00 03` | `laser.cmd_laser_off` |
| 开启激光 | `55 AA 03 01 04` | `laser.cmd_laser_on` |

**功率设置算法:**
1. 将十进制 mW 值转为 2 字节十六进制 (高字节在前)
2. 校验和 = `05 + 01 + 高字节 + 低字节`，取低 8 位
3. 示例: 100 mW → `00 64` → 校验和 `6A` → `55 AA 05 01 00 64 6A`

**软件输入范围:** 0 ~ 1500 (超出激光器设定范围 150 时，输出钳位到最大值)

### 4.4 安全限制

**光学安全:**
- 禁止直视激光或散射辐射
- 必须佩戴护目镜，不要直视光斑或高反射面
- 反射面 (镜子、玻璃、金属) 可引起严重伤害
- 禁止在易燃易爆环境中使用
- 不使用或无人值守时必须完全关闭激光器
- 确保激光高度不在视线水平附近
- 操作区必须张贴警告标志，限制非操作人员进入
- 不可见激光使用前需用红外检测仪或红外显示卡检查

**电学安全:**
- 禁止擅自打开激光器封盖或电源外壳 (保修失效)
- 断开/连接激光头与电源必须在断电状态下进行
- 设备停止使用时立即切断主电源
- 保持激光头与同序列号电源紧密连接 (防静电损坏)
- 电源接通后勿触碰外露线路和元件
- 维护时使用绝缘工具
- 系统必须正确接地 (防雷击、静电、电磁干扰)
- 仅连接额定电压匹配的电源

**使用环境:**

| 参数 | 要求 | 备注 |
|------|------|------|
| 环境温度 | 10 ~ 35°C | 温度变化须缓慢 |
| 底板温度 | 25 ± 3°C | 建议值 |
| 相对湿度 | <90% | |
| 主电源电压 | 额定值 ±10% | |
| 通风距离 | 通风口 0.05 ~ 0.1m 无遮挡 | |
| 海拔 | 未指定 | |
| 清洁度 | 清洁、干燥、无尘、无静电 | |

**操作规程:**
1. 检查电源开关置于 OFF
2. 按标识连接电源
3. 如需调制，接入 BNC 信号线 (先黑后红)
4. 连接 USB 转 RS232 线
5. 打开电源开关 (Power 灯亮)
6. 打开钥匙开关 (约 5s 后 Laser 灯亮)
7. 室温下约 10 分钟后稳定工作
8. 关闭: 先关钥匙开关，再关电源开关，拔电源插头

**报警处理:**
- Alarm 灯亮: 关闭电源开关，几分钟后重新开启
- 如仍未恢复: 关闭系统，联系 CNI

**光纤操作:**
- 每次使用前用乙醇棉签擦拭光纤头
- 切勿触摸光纤头表面
- 光纤最小弯曲直径: 200μm 光纤 → 运输 50mm / 运行 65mm
- 连接时先斜角接触再转平直插入
- 不使用时盖上光纤帽

## 5. 软件安全约束

### 5.1 功率限制 (三级校验)

```
GUI 前端警告 → CommandService._check_power_limit() → Driver.validate_power()
     80% 橙色        SafetyError 异常               硬限制 -120~+30 dBm
     95% 红色
    100% 禁止
```

### 5.2 频率范围

| 参数 | 最小值 | 最大值 |
|------|--------|--------|
| SMB100A 频率 | 100 kHz | 12.75 GHz |

### 5.3 急停流程

1. 关闭 RF 输出 (`OUTP OFF`)
2. 关闭 LF 输出
3. 关闭 FM 调制
4. 切回 CW 模式 (`FREQ:MODE CW`)
5. 停止正在进行的扫频
6. 停止锁相采集

### 5.4 线程安全

| 约束 | 说明 |
|------|------|
| 单线程命令总线 | 所有设备操作串行执行，避免 VISA/Serial 并发竞争 |
| GUI 禁用 submit_sync() | 阻塞事件循环，只能用 submit() + 信号回调 |
| I/O 全加锁 | `threading.Lock` / `RLock` 保护所有驱动 I/O |
| Worker 只读 | SMBPoll / LockinMonitor / LockinAcquire 直接访问 Driver |
| _SweepRunner 无 parent | `super().__init__(None)` 确保 moveToThread 安全 |
| VISA 枚举短超时 | 500ms，避免 hang 在无效资源上 |
| RALL? 数据校验 | `len(raw) == 12288`，不完整数据丢弃 |
| Parquet 关闭 | `finally` 块中确保 `writer.close()` |

## 6. 配置文件说明

配置文件 `config.json` 位于项目根目录，`load_config()` 自动与 `DEFAULT_CONFIG` 深度合并。

### 6.1 配置节一览

| 节 | 说明 |
|------|------|
| `smb` | SMB100A 连接与安全参数 |
| `lockin` | OE1022D 串口通信参数 |
| `laser` | 激光器串口通信与性能参数 |
| `lockin_bindings` | 锁相放大器 SN → COM 映射 |
| `smb_bindings` | SMB 序列号 → VISA 地址映射 |
| `sweep` | 扫频序列默认参数 |
| `acquisition` | 数据采集参数 |
| `ui` | GUI 显示参数 |

### 6.2 关键安全配置

```json
{
  "smb": {
    "amplifier_installed": true,     // 有放大器时限 10 dBm，无时限 25 dBm
    "max_power_with_amp_dbm": 10,
    "max_power_without_amp_dbm": 25,
    "freq_range_hz": [100000, 12750000000]
  },
  "laser": {
    "max_power_mw": 150,             // 功率设定上限
    "warmup_s": 600                  // 建议预热时间
  },
  "lockin": {
    "rall_total_bytes": 12288        // RALL? 数据完整性校验基准
  }
}
```
